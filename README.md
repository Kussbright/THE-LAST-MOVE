# THE LAST MOVE — Official Website

Official website for **THE LAST MOVE**, an original documentary brand exploring engineering, technology, science, and the decisions behind the systems that shape our world.

## Brand Identity
- **Tagline**: *Stories Behind a Complex World.*
- **Core Pillars**: Engineering · Technology · Science
- **YouTube Channel**: [@TheLastMoveTV](https://www.youtube.com/@TheLastMoveTV)
- **Contact & Inquiries**: thelastmovetv@gmail.com

## Site Architecture
- `index.html` — Homepage with dynamic blueprint grid animation, editorial overview, story layers, and YouTube CTA.
- `documentaries.html` — The Documentary Archive with category tags, upcoming production notes, and structured empty state.
- `stories.html` — Editorial companion pieces, explainers, and longform articles.
- `about.html` — Brand mission, editorial philosophy, inquiry information, and social connections.
- `css/` — Modular styling system (variables, typography, components, hero, pages, responsive).
- `js/` — Interactive navigation, dynamic hero canvas animation (30fps capped, respects `prefers-reduced-motion`), and content data model (`data.js`).
- `assets/` — Brand assets (logo, banner, open-graph social card).
- `sitemap.xml` & `robots.txt` — Production-ready SEO configurations.

## Development & Deployment
Static site with zero dependencies or build steps required. Can be deployed directly to Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any static web hosting.
